# Third-party assets used by Kente Kickers

All player and referee models and animations are free, public-domain style assets. No assets
from any other football game are used; kits, numbers, clubs and players are generated by the game.

| File | Source | Author | Licence |
|---|---|---|---|
| `assets/models/player.glb.b64` (rigged humanoid, two LODs) | Universal Base Characters — "Superhero Male" body, https://quaternius.itch.io/universal-base-characters (obtained via the public mirror in github.com/lord3nd3r/ffxi-browser) | Quaternius | CC0 1.0 (public domain) |
| `assets/models/ual-anims.json` (Idle, Walk, Jog, Sprint, Jump, Roll, Hit, Crouch, etc.) | Universal Animation Library, https://quaternius.itch.io/universal-animation-library (obtained via the J-Ponzo public mirror) | Quaternius | CC0 1.0 (public domain) |
| Football-specific clips (pass, shot, lofted kick, slide, header, throw-in, GK set/dives/catch, celebrations, referee) | Authored in code in `js/players3d.js` for this game | Kente Kickers | Same as the game |
| `js/vendor/three.module.min.js`, `three.core.min.js`, `three-addons.min.js` (GLTFLoader, SkeletonUtils) | https://github.com/mrdoob/three.js (r180) | three.js authors | MIT |
| MeshoptDecoder (inside `three-addons.min.js`) | https://github.com/zeux/meshoptimizer | Arseny Kapoulkine | MIT |

Processing: the model was re-exported (decimated LOD1, quantised, kit/skin/hair regions packed into
vertex attributes) and the animation clips were resampled into compact JSON by build scripts.
No Mixamo content is included.
